# MiGreat Fit-Check Widget

"Are You in Demand in Germany?" — a self-service assessment tool for skilled professionals considering careers in Germany.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS

## Pages

- `/` — Landing page with hero and CTA
- `/fit-check` — 4-step assessment widget with personalized results

## Notes

- All assessment logic runs client-side (no backend required)
- Lead capture currently logs to console (placeholder for future API)
- Designed for integration into the main MiGreat website
